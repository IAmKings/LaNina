## 0. 阅读指引

- 系统里每条论点目前各有四条规则：`<前缀>-support`（支撑）、`-refute`（证伪）、`-invalidate`（失效）、`-relief`（缓解）。这些规则的 id 是稳定命名，升级时**保持不变**。

- 本文为六条论点逐条给出：现状 → 建议的数值比较规则（左值/操作符/阈值/窗口）→ 依据引用 → 反例场景 → 保留/升级建议。
- ⚠️ 标记的条目表示**依据不足**：研究报告与 PRD 没有给出可以直接采用的数字。此时本文不编造数值，给出「暂缓」或「请负责人给定数值」两个选项，两者都是合法结论。

## 1. 全局口径（适用于全部六条，先读这一节）

### 1.1 numeric_compare 是什么、不是什么（研究者视角）

数值比较规则回答的问题是：**「某一个指标的最新一个观测值，是否越过了一条写死的分数线」**。它有四条硬边界，直接决定了哪些论点今天能落地、哪些不能：

| 能力 | 说明 |
|---|---|
| 左值 | **单一指标**的最新一条通过有效性筛选的观测（观测时点最新优先；同一观测期取最高修订版）。不能跨指标相减、不能算同比、不能对五年均值求比。 |
| 操作符 | `>`、`≥`、`<`、`≤` 四选一，阈值是固定常数，单位必须与观测单位逐字一致（如 `°C`、`mm/day`）。 |
| 数据窗口 | **没有滚动窗口**。「窗口」实际上由指标自身的统计形态决定——例如 RONI 本身就是三个月滑动距平（自带窗口），而区域降水代理目前是「单日区域均值」（无窗口、噪声大）。 |
| 命中后果 | 命中只影响方向判定与「阈值触发」类最新变化；不改变置信度公式，不自动推进阶段。 |

由此推出两条重要限制：

1. **「增强/减弱」这种趋势语义，numeric_compare 表达不了**——它只能表达「处于某区间」。若论点 label 写的是「增强」，用数值规则落地后的真实语义是「事件确立/处于某档」，label 措辞是否随之调整属于种子内容变更，需要您签字。
2. **需要派生指标（距平 %、同比 %、对五年均值比）的阈值，必须先新增指标才能落地**。PRD §8.3–8.5 已定义了这些派生指标名（如 `thai_rain_anomaly_30d_pct`），但均未接入。新增指标走「只增不改」迁移纪律，是独立的数据接入工作。

### 1.2 方向是怎么产生的（决定「哪条规则值得数值化」）

- 方向由规则 id 后缀决定：`-support` → 偏多（bullish）；`-refute`、`-relief` → 偏空（bearish）；`-invalidate` → 不主张方向。**操作符只决定「何时命中」，方向永远跟着 id 后缀走。**把操作符写反而不改 id，会产出语义完全颠倒的方向（见各条目「反例场景」）。
- 命中证据的立场（stance）必须与规则类别一致：support 规则要求 `supports` 立场证据，refute/relief/invalidate 规则要求 `refutes` 立场证据。**当前六个种子的全部数据 selector 都是 `supports` 立场（欧线 Brent 是 `context`）**，所以 refute/relief/invalidate 三类规则在方向计算中不可达。**数值化落地后，方向只有两种取值：偏多（阈值满足时）或暂不判定（不满足时）。**偏空方向要等未来接入 `refutes` 立场的反向数据源，本文各条目的反向侧数值化因此一律暂缓。
- D1 过渡守卫：命中的方向规则若**全部**是存在性规则，方向输出 unavailable。只要有一条数值比较规则参与命中，守卫即解除。控制变量（如欧线 Brent）与 context 立场证据不参与方向计算——**对欧线论点，任何以 Brent 为左值的数值规则都无法让方向恢复 available**。

### 1.3 「数据窗口」一栏怎么读

下文每条建议都有一行「数据窗口」。它的真实含义是「左值取自哪段观测」：

- ENSO-CORE-01：最新一个已完成三个月季节的 RONI 值（NOAA 月度表，自带季节窗口；最近两个季节 NOAA 标注为估算值、会被修订，规则自动取最新修订版）。
- 四条降水代理：**最新单日**的区域均值——这正是它们暂缓的主因之一（见 1.1 第 2 条限制）。
- USDA 估计：最新 marketing-year 估计值（年度水平值，跨年不可比，见 PALM/MAIZE 条目）。
- Brent：最新单日现货价（仅作控制变量，不参与方向）。

## 2. 逐条工作表

### 2.1 ENSO-CORE-01 —— 唯一具备直接数值依据、可立即签字落地的条目

**论点**：当前 ENSO 强度与持续时间是否继续增强（市场范围：RONI/ONI 与区域风险窗口）
**现有规则**：`enso-support` / `enso-refute` / `enso-invalidate` / `enso-relief`，全部为存在性规则（selector `enso-roni`，命中即算）。

**建议谓词（新增一条数值规则，不动现有四条）**

| 项目 | 建议 |
|---|---|
| 规则 id | `enso-numeric-support`（保持 `-support` 后缀 → 偏多；命名约定 `<前缀>-numeric-<后缀>`，见 §2.7 说明） |
| 左值 | `enso_roni_ersstv6`：NOAA RONI（ERSSTv6 口径），三个月季节值，单位 `°C` |
| 操作符/阈值 | **推荐：`≥ +0.5°C`**（NOAA 官方档位中「弱」的下限，即厄尔尼诺事件确立线） |
| 备选 | `≥ +2.0°C`（报告明示的「很强」门槛，方向 available 窗口显著更窄） |
| 数据窗口 | 最新已完成季节（最新修订版）；来源 SLO 45 天 |

**依据**

> 研究报告「结论先行」第 2 条：「NOAA 的正式强度档为弱、中等、强、很强，其中 RONI ≥ +2.0°C 才是"很强"。因此截至本报告日，更严谨的说法是：厄尔尼诺已建立、正在增强……」

> 研究报告 §一（末段）：「截至 2026 年 JJA（6–8 月）的 NOAA RONI 估计为 +1.4°C，即已完成三个月季节按 NOAA 档位仍属"中等"」——说明档位阶梯（中等 = 1.0–1.5）在报告中被实际使用。

> 研究报告 §六（基准情景）：「RONI 在 2026 年末达到 ≥+2.0°C，2027 年春季后减弱」——+2.0 是「很强」事件的确认线，而非事件确立线。

说明与⚠️：**+0.5 这个具体数字报告正文没有直印**（报告链接的 NOAA 官方档位表为出处，报告只明示了 ≥+2.0 的「很强」档）。按本研究「不编造精确数字」的纪律，+0.5 作为推荐值需您确认采用官方弱档下限；若您认为该论点方向只在「很强」事件中才有资格判偏多，请选备选 +2.0。另外：数值规则的真实语义是「厄尔尼诺事件区间内（风险窗口激活）」，不是字面的「增强中」；`enso-support` 的 label「ENSO 强度与持续性增强」是否据此改为「厄尔尼诺事件确立」，请您一并定夺（label 属种子内容=签字事项）。

**反例场景（阈值取反/挪动时方向语义如何变化）**

- 操作符取反（`< +0.5`）而 id 后缀仍是 `-support`：RONI 低于 0.5（中性/拉尼娜年）时反而输出偏多——方向语义整体颠倒。操作符与后缀必须成对审核，绝不允许只改其一。
- 阈值升到 +2.0：仅历史级事件判偏多；当前 +1.4 属「中等」时方向 unavailable——对外表现回到过渡期观感（方向列灰）。
- 阈值降到 0：中性年份也恒偏多——正是 D1 之前「有证据即 bullish」退化的复现。
- 恰好等于阈值：RONI = +0.5 时按「≥」命中（NOAA 官方口径为「达到或超过」）；边界语义与 §5 的容差统一口径一致。

**保留/升级建议：组合。** 保留 `enso-support`（存在性，继续供阶段门使用）；新增 `enso-numeric-support`（方向条件）。不推荐「替换」：替换会让五个阶段门全部要求数值命中，阶段语义被一次性改写，超出本任务范围。

**refute/invalidate/relief 三条数值化：⚠️ 依据不足，暂缓。** 偏空方向需要 `refutes` 立场的反向 selector（如独立机构与 NOAA 相悖的确认），当前未接入；报告也把独立确认列为缺口（种子 coverageGap `enso-independent-confirmation`）。

**需要您决定的事项**：(a) 阈值 +0.5 还是 +2.0；(b) `enso-support` label 是否改写。

### 2.2 RUBBER-TH-01 —— 降水阈值无研究数字，且现指标统计形态不支持，暂缓

**论点**：泰国主产区天气是否减少割胶并收紧天然橡胶原料（市场范围：RU、NR、TSR20、RSS3）
**现有规则**：`rubber-support/refute/invalidate/relief`，全部存在性规则（selector `rubber-rainfall-proxy`，命中即算）。

**建议谓词：⚠️ 依据不足，暂缓数值化。**

理论上 support 规则的语义是「偏干 → 原料收紧 → 偏多 RU 近月」，左值应为降水**负距平**。但两个前置条件都不成立：

1. **没有数字**：报告与 PRD 均未给出任何可用的降水阈值（多少毫米、负距平百分之几、连续多少天）。
2. **统计形态不支持**：现有指标是 NASA 点位等权的**单日**区域均值（`mm/day`）。让「最新一天下没下雨」决定一条 2–8 周论点的方向，研究上站不住；单日噪声会使方向在旱/雨日之间来回翻转。

> PRD §8.3（核心派生指标）：「`thai_rain_anomaly_30d_pct`；`thai_heavy_rain_days_14d`；……」——窗口化距平指标已在 PRD 定义但**尚未接入**。

> PRD §18（开发开始前必须确认的业务输入）第 6 项：「每条论点的首版阈值与连续确认次数」——PRD 本身把首版阈值列为待研究确认事项，而非已定数字。

> 研究报告 §三（天然橡胶行）：「东南亚/印度偏干；……高度依赖品种、海拔和生长阶段，方向弱于"产区实测"」——报告刻意不给单边数值。

**目标形态（供未来签字参考，数值留空待您给定）**：`thai_rain_anomaly_30d_pct < ____%`（30 日降水距平相对常年），需先接入派生指标（只增不改）。

**反例场景**：若强行在单日均值上定 `lt 阈值`：雨季正常日普遍高于旱季阈值，方向随单日降水翻转，每日简报会集中出现方向变化审核；若误写 `gt 阈值` 而后缀仍是 `-support`，会输出「雨水偏多 → 看涨橡胶」的语义颠倒（橡胶偏多的驱动是偏干）。

**保留/升级建议：维持现状（仅存在性规则）。** 方向在该论点接入窗口化距平指标、您给定阈值前保持 unavailable——这是 D1 选项 A 的既定语义，不是回归。若您希望尽快恢复方向 available，需要给出可接受的近似数字（工程侧无权代签）。

### 2.3 PALM-SEA-01 —— 降水同橡胶；USDA 水平值无跨年可比阈值，暂缓

**论点**：印尼与马来西亚水分压力是否滞后压低棕榈油产量（市场范围：棕榈油及棕榈油—豆油价差）
**现有规则**：`palm-support/refute/invalidate/relief`，全部存在性规则（selectors：降水代理 + USDA 马来西亚棕榈油产量/出口/库存估计，命中即算）。

**建议谓词：⚠️ 依据不足，暂缓数值化。** 两类左值各有障碍：

1. 降水代理：与 §2.2 完全相同（单日均值、无研究数字）。
2. USDA 三条指标是 **marketing-year 年度水平值**（单位 1000 MT）。numeric_compare 只能拿水平值对固定分数线比，而「产量 1900 万吨算多还是少」逐年漂移，任何固定阈值都不具研究含义；同比/对五年均值比需要派生指标，现指标算不出来。

> PRD §8.4（核心派生指标）：「`mpob_production_yoy_pct`；`mpob_inventory_months`；`sea_rain_anomaly_90d_pct`……」——正确统计形态已定义，均未接入。

> 研究报告 §二.3（第二点）：「2023 年马来西亚的实际降水一度接近正常，USDA 当时并未机械地下调全部产量，说明必须等待产区实测。」——报告明确反对把降水信号机械转写为产量方向。

**目标形态**：`mpob_inventory_months > ____`（库存月数）或 `mpob_production_yoy_pct < ____%`，待 MPOB/USDA 派生指标接入后由您给定。

**反例场景**：若在 USDA 库存水平值上强行定 `lt 固定值`： marketing-year 换年时同一阈值含义漂移，方向可能在库存未发生实质变化的年份间无故翻转；降水侧取反则同 §2.2（且「偏干=偏多棕榈油」写成 `gt` 会语义颠倒）。

**保留/升级建议：维持现状。**

### 2.4 MAIZE-SA-01 —— 历史影响量级 ≠ 可用阈值，且缺百分比统计形态，暂缓

**论点**：南部非洲主种植季偏干是否降低次年玉米供应（市场范围：区域玉米与 CBOT 玉米间接参考）
**现有规则**：`maize-support/refute/invalidate/relief`，全部存在性规则（selectors：降水代理 + USDA 南非玉米产量/出口/库存估计，命中即算）。

**建议谓词：⚠️ 依据不足，暂缓数值化。** 障碍与 §2.3 相同（单日降水、USDA 水平值）。报告里有历史上每一次事件的实际冲击量级，但那些是「发生过的事实」不是「阈值」：

> 研究报告 §二.2（2015–16 行）：「FAO 当时估计南非玉米产量较前一年下降 25%、较五年均值低 36%」；（2023–24 行）：「南部非洲 2024 年谷物单产较五年均值低 16%，赞比亚/津巴布韦分别低 43%/50%」。

这些数字如果要用作阈值（例如「产量较五年均值 −15% 即判供应受压」），前提是存在「对五年均值比」的派生指标——现指标（USDA marketing-year 水平值，1000 MT）算不出该比值。是否采纳 −15% 一类的线、以哪个历史分布为基准，是纯研究决定，本文不代拟。

> PRD §8.4（核心派生指标）：「`sa_maize_rain_anomaly_crop_window_pct`；`sa_maize_estimate_revision_pct`；`sa_maize_import_gap_tonnes`」——均未接入。降水代理的 selector 注释也明言「尚未固化 11–3 月作物窗口」。

**目标形态**：`sa_maize_estimate_revision_pct` 或「产量较五年均值 %」类派生指标 + 您给定的分数线；降水侧需先固化 11–3 月农时窗口再谈阈值。

**反例场景**：同 §2.3（水平值阈值跨年漂移；「偏干=偏多」误写成 `gt` 语义颠倒）。附加：若把报告历史数字（−25%）直接当 USDA 水平值阈值，会把「某年发生过的结果」错用为「每年的判据」。

**保留/升级建议：维持现状。**

### 2.5 SHIP-USEC-01 —— 报告有具体数字但对应指标未接入，暂缓（可回填）

**论点**：巴拿马水约束是否提高亚洲至美东航线时间和成本（市场范围：美东即期运价、等待时间与绕航）
**现有规则**：`usec-support/refute/invalidate/relief`，全部存在性规则（selector `usec-panama-rainfall-proxy`，命中即算）。

**建议谓词：⚠️ 暂缓，但这是六条中最接近可落地的「未来条目」。** 报告记录了当前周期的具体运营数字：

> 研究报告「结论先行」第 4 条：「2026-09-03 起新巴拿马型船闸日配额为 9 个、巴拿马型船闸为 25 个，并计划 09-15 再降至 23 个。09-05 的最新决定维持新巴拿马型船舶 48 英尺最大吃水」

> 研究报告 §五.2：「1. Gatún/Alhajuela 湖水位与流域实际降水；2. 每日配额、最大吃水、预约/拍卖价格和无预约等待时间；3. 实际船舶转向……」——报告给出的验证顺序中，ACP 运营数字排在流域降水之前。

障碍：`panama_daily_slots`、`panama_max_draft_ft`、`gatun_level_vs_seasonal_pct`、`panama_waiting_days` 等 ACP 数值指标（PRD §8.5 已定义）**均未接入**（种子 coverageGap `usec-acp-numeric` 与此对应）；现有左值只有流域降水的单日代理，同 §2.2 不宜数值化。

**目标形态（待 ACP 适配器接入后回填签字）**：例如 `panama_daily_slots ≤ ____`（以 ACP 公告值为线，如 23）、`panama_max_draft_ft < ____`（如 48）。届时这些阈值有 ACP 官方公告直接背书，依据等级是六条里最高的。

**反例场景**：若现在用单日降水代理定 `lt 阈值`：流域降水与运河实际限航是两个层级（报告 §五.2 的验证顺序 1→2），单日少雨不等于配额下降，方向会先于真实约束翻转；误写 `gt` 则「多雨 → 看涨美东运价」语义颠倒（该论点偏多的驱动是缺水限航）。

**保留/升级建议：维持现状；把「ACP 指标接入后回填数值阈值」记入后续研究待办。**

### 2.6 SHIP-EU-01 —— 结构性不可达，暂缓（方向 unavailable 是设计语义）

**论点**：ENSO 相关因素对亚洲至欧洲航线是否存在可分离影响（市场范围：SCFI 欧线、EC 与船期可靠性）
**现有规则**：`eu-support/refute/invalidate/relief`，全部存在性规则（唯一 selector `eu-brent-control`：EIA Brent 现货，控制变量层、`context` 立场、权重 0）。

**建议谓词：⚠️ 依据不足，且数值化在本论点上结构性无效——暂缓。**

关键事实：控制变量与 context 立场证据**不参与方向计算**（2026-09-24 D3 签字口径：control 层权重 0，「参与解释与门禁，不参与方向计算」）。因此哪怕给 Brent 定任意阈值，方向判定中该证据仍被排除，D1 守卫之外的另一道 CONTEXT_ONLY 门槛会继续把方向压为 unavailable。**本论点不存在「落地数值规则后方向恢复 available」的路径。**

研究依据也支持不设阈值：

> PRD §5.1（六条首发影响论点表后注）：「`SHIP-EU-01` 默认方向为"分化/待验证"。不得因为巴拿马运河受限就自动判断欧线偏多。」

> 研究报告 §五.1：「巴拿马运河扰动对 2023-10 至 2024-06 中国集装箱运价指数累计上涨贡献约 9 个百分点，明显小于红海/苏伊士冲击」——同一运河冲击在欧线上是次要因子，不存在可单列的「ENSO 欧线阈值」。

> PRD §8.6：「必须拆分以下因子，不得把总运价变化全部归因于 ENSO：……红海/苏伊士（P0 首要混杂因素）、运力、需求……」

**反例场景**：若强行给 Brent 定阈值并视作方向条件：Brent 涨跌同时受地缘与原油周期驱动，与欧线运价的关系是「燃油成本」而非「ENSO 归因」，方向字段会输出一条 PRD 明令禁止的自动归因（「不得因为巴拿马运河受限就自动判断欧线偏多」同理适用于 Brent）。

**保留/升级建议：维持现状。** 方向保持 unavailable 与 PRD「默认分化/待验证」一致；红海/运力/需求控制变量与欧线持牌运价接入、并定义归因规则之后，才重新讨论（届时也可能是 `manual_review_required` 的人工归因路径而非数值阈值）。

## 5. 容差统一建议（二选一：推荐统一到 4×EPSILON 缩放容差）

**背景**：数值比较规则目前是严格比较（无容差）；而「重大变化」模块对「修订幅度是否达标」用的是含 4×EPSILON 缩放容差的口径（`meetsInclusiveDelta`：实际幅度达到要求值，或与要求值之差在 4×EPSILON×max(1, 双方绝对值, 要求值) 以内也算达标）。同一类「数值越过分数线」的判断存在两套口径（批次二领域层 L6 记录在案）。

**推荐：统一到「4×EPSILON 缩放容差 + 操作符自带的含等语义」。** 具体语义：

1. 若 |观测值 − 阈值| ≤ 4×EPSILON×max(1, |观测值|, |阈值|)，视为「恰好等于阈值」；
2. 等于阈值时：`≥`、`≤` 命中，`>`、`<` 不命中；
3. 其余按字面比较。

**理由**：

- **研究语义零影响**：4×EPSILON 是 10⁻¹⁵ 量级的相对容差，而本研究数据的精细刻度最小是降水的 0.0001 `mm/day`（RONI 0.1°C、USDA 1000 MT 整数、Brent 0.01 USD/bbl）。容差只吸收 IEEE754 表示误差（例如均值累加产生的 `0.30000000000000004` vs `0.3`），不可能翻转任何真实研究决定。
- **消除边界悖论**：严格比较下，「恰好等于阈值」完全依赖上游十进制取整恰好落在二进制可精确表示的数上；一旦某适配器输出经过浮点累加，±10⁻¹⁶ 的表示误差就会让两条本应一致的判断（方向判定 vs 修订达标判定）在同一个边界值上给出相反答案。
- **一处口径、一处测试**：统一后，R3 要求的「恰好等于阈值」边界测试只需一种解释；阈值 entered/exited（最新变化）与方向判定不会互相矛盾。
- 反方案（统一到严格比较）的代价：要么给 material-change 加严格口径（改变已签字的「达到即算」语义，属种子/策略内容变更），要么两处分裂永久保留——都不如向数值比较侧补容差合理。

实现方式（共享一个判定 helper）属 R2 工程事项，本工作表只锁定口径。**请确认：采用推荐口径。**

## 6. 落地后 D1 过渡守卫的影响预测

守卫机制回顾：命中的方向规则若全部是存在性规则，方向输出 unavailable（理由注明「数值比较规则尚未上线」）；任何数值规则参与命中即解除守卫。

按 §3 结论表逐条预测：

1. **ENSO-CORE-01（假设签字 ≥ +0.5°C）**：RONI ≥ +0.5 的典型证据下（如当前 JJA +1.4），方向恢复 available、输出偏多，守卫自然不触发。RONI < +0.5 时无数值规则命中，方向仍 unavailable——但理由变为「没有具备方向性证据的已审核规则命中」，这是阈值语义而非守卫回归，页面观感与过渡期相同（方向列灰）。
2. **RUBBER/PALM/MAIZE/USEC（暂缓）**：守卫继续触发，方向维持 unavailable。若后续您给定阈值，按第 1 条同款机制解除。
3. **SHIP-EU-01（结构性不可达）**：与守卫无关，CONTEXT_ONLY 门槛使方向维持 unavailable，等同 PRD「默认分化/待验证」。
4. **每日简报**：方向 available 后，方向变化触发的高风险审核（DIRECTION_CHANGE）恢复活跃。首期 ENSO-CORE-01 从 unavailable → 偏多本身构成一次方向变化，按 CONTEXT.md「高风险转场」需绑定上一版/目标版的人工审核记录；上线说明应提示首期可能集中出现此类审核（PRD R4）。
5. **快照影响（R4 逐条声明范围）**：`thesis-evaluation-scenarios` 中仅 ENSO-CORE-01 的方向值、命中规则与理由变化；其余五种子快照不变。注意黄金场景数据里 ENSO 的「反证」场景值恰为 0.5（等于建议阈值），按「≥ 含等」口径该场景方向将变为 available 偏多——这条边界快照 diff 需在实现时显式声明，并作为「恰好等于阈值」的对照测试。
6. **守卫本体保留不删**（D1 决策与 PRD 约束）：它对「未来新增的、又只有存在性规则的种子」仍是保险丝。
