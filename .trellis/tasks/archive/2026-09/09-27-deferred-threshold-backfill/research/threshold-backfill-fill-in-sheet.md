## 1. 逐条填空件

### 1.1 RUBBER-TH-01（泰国橡胶）

- 论点：主产区偏干 → 割胶减少 → 原料收紧 → 偏多 RU 近月。现有规则 `rubber-support/refute/invalidate/relief`（存在性）不变。
- **候选 A（推荐，需 P-工程 L1-a + P-研究）**：
  `thai_rain_anomaly_30d_pct < ____ %`（30 日降水距平相对常年，PRD §8.3 `thai_rain_anomaly_30d_pct`）
- **候选 B（需 P-工程 L1-a + P-研究）**：`thai_heavy_rain_days_14d > ____ 天`（14 日强降雨天数，PRD §8.3；用于 refute/relief 侧）
- ❌ 不提供的选项：在现有单日均值（`mm/day`）上直接定阈值——单日噪声会使方向随旱/雨日翻转，工程与 research 口径都不支持。
- **需要您提供**：① 候选 A/B 的数值；② 距平基准期定义（如 WMO 1991-2020，或您指定的基准）；③ 若选 B，「强降雨」的日降水下限（mm/day）。
- 签字：阈值 ________，基准期 ________，签字 ________ 日期 ________

### 1.2 PALM-SEA-01（印尼/马来西亚棕榈油）

- 论点：水分压力滞后压低产量 → 偏多棕榈油/豆油差。现有规则不变。
- **候选 A（需 P-工程 L1-b + P-研究）**：`usda_malaysia_palm_ending_stocks_yoy_pct > ____ %`（期末库存同比；USDA 数据已在采集，只缺同比派生层）
- **候选 B（需 P-工程 L2-b 新源 MPOB + P-研究）**：`mpob_inventory_months > ____`（库存月数，PRD §8.4）
- **候选 C（需 P-工程 L1-a + P-研究）**：`sea_rain_anomaly_90d_pct < ____ %`（90 日降水距平，PRD §8.4）
- **需要您提供**：选 A/B/C（可组合）+ 各自数值 + 依据。
- 签字：所选候选 ________，阈值 ________，依据 ________，签字 ________ 日期 ________

### 1.3 MAIZE-SA-01（南部非洲玉米）

- 论点：主种植季偏干 → 次年供应下降。现有规则不变。
- **候选 A（推荐，需 P-工程 L1-b + P-研究）**：`sa_maize_production_vs_5yr_mean_pct < -____ %`（产量对五年均值比；USDA 数据已在采集，只缺五年均值比派生层）
  - 参考（非阈值）：报告历史事实为 2015-16 较五年均值 −36%、2023-24 −16%（§2.4 引文）。采用哪条线、以哪个分布为基准是纯研究决定。
- **候选 B（需 P-工程 L1-a + 窗口固化 + P-研究）**：`sa_maize_rain_anomaly_crop_window_pct < ____ %`（需先固化 11–3 月作物窗口，selector 注释已声明未固化）
- ❌ 不提供的选项：在 USDA 年度水平值（1000 MT）上定固定分数线——跨年漂移无研究含义。
- **需要您提供**：候选 A 的分数线与基准分布定义（五年均值？剔除异常年？），或候选 B 的窗口与数值。
- 签字：所选候选 ________，阈值 ________，基准 ________，签字 ________ 日期 ________

### 1.4 SHIP-USEC-01（巴拿马运河 → 美东）——依据最硬，等新源接入

- 论点：运河水约束 → 航时/成本上升 → 偏多美东运价。现有规则不变。
- **候选 A（需 P-工程 L2-c 新源 ACP + P-研究）**：`panama_daily_slots ≤ ____`（日配额；ACP 公告直接背书，如当期 25/23）
- **候选 B（需 P-工程 L2-c + P-研究）**：`panama_max_draft_ft < ____`（最大吃水，如 48 英尺）
- 前置说明：PRD §8.5 已定义 `panama_daily_slots` / `panama_max_draft_ft` / `gatun_level_vs_seasonal_pct` / `panama_waiting_days`；种子 coverageGap `usec-acp-numeric` 对应此缺口。ACP 为新数据源，接入前需走来源发布登记册的权利预审（`docs/operations/source-release-register.md` 流程）。
- **需要您提供**：① 确认 ACP 官方公告页为数据源并授权接入预审；② 各指标阈值（公告值即依据）。
- 签字：确认数据源 ________，阈值 ________，签字 ________ 日期 ________
