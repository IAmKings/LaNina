| | |
|---|---|
| **致** | 研究负责人 + 产品负责人（可合并为一次评审） |
| **发起** | ENSO 市场影响监测平台（项目负责人：kuluoluo） |
| **日期** | 2026-09-15 |
| **建议回复期限** | 5 个工作日内（本组决定聚合能否产出任何草稿） |
| **一句话** | 六条影响论点目前全部处于 `reviewStatus=pending`，系统因此在生成草稿前就拒绝执行（`PENDING_RESEARCH_APPROVAL`）；需要你们逐条确认区域定义、市场范围、阈值与失效条件，系统才能产生草稿。 |

## 一、为什么需要你

1. 这是**唯一**无法用工程手段绕过的前置条件：未签字时每天 06:30 的聚合对六条论点**全部**
   返回 `PENDING_RESEARCH_APPROVAL`，`draftsReady = 0`（本地已实测复现）。
2. 未签字时系统按设计只产生空状态，**不会**公开任何方向、阶段或置信度——这是安全默认，不是故障。
3. 签字同时决定"数据覆盖不足"如何对外表达；在缺少合规来源时，宁可显示缺口，也不能用替代数据
   提升置信度或写成价格归因。

## 二、需要确认的事项（逐条）

- [ ] **D1 论点身份**：六条论点的中文标题、研究责任人、适用地区与市场期限
      （PRD §18 第 2 项；标题当前已是产品级文案，需确认定稿）。
- [ ] **D2 区域定义**：各区域降水 polygon 或省份清单；当前种子标记为
      `regionDefinitionVersion: *-pending-review`，需给出定稿版本号
      （PRD §18 第 5 项）。
- [ ] **D3 阈值与连续确认次数**：每条论点的首版阈值、连续确认次数与比较口径
      （PRD §18 第 6 项）。所有 selector / SLO / rule / threshold 目前均为 `pending` 且不可用。
- [ ] **D4 传导阶段门槛**：六个阶段（观察 → 区域天气兑现 → 实物受压 → 供需收紧 → 市场确认 → 缓解）
      进入门禁的业务解释，特别是"禁止越级"的判定（PRD §7.2）。
- [ ] **D5 方向与置信度策略**：方向口径（偏多/偏空/中性/分化）与四项权重
      （覆盖 / 新鲜度 / 来源质量 / 证据一致性）；确认三项硬上限：仅预测 ≤49、必需层过期 ≤59、
      未解释冲突 ≤69（PRD §7.4）。
- [ ] **D6 失效条件**：每条论点"一旦满足即要求降级/反转/关闭"的条件文案。
- [ ] **D7 来源资格**：每个证据层允许使用哪些来源；以及当前 coverage gap 的对外标签与话术
      （例如橡胶日频市场、Panama 一手数据、MPOB 月度实际；见来源登记册）。
- [ ] **D8 发布安排**：首月是否全部人工发布（建议：是；自动发布默认关闭），以及后台
      editor / publisher 名单（PRD §18 第 7、8 项）。
- [ ] **D9 告警接收人**（PRD §18 第 9 项，可与 C 组共用）。

> D7 与来源许可（A 组）交叉：若某来源未获书面授权，请直接确认该论点保持"数据覆盖不足"，
> 不要以代理数据替代。

## 三、当前状态（供评审时对照）

| 项目 | 现状 |
|---|---|
| 六条种子 | 均为 `evaluation-v1-draft`，`reviewStatus=pending`，生产评估与生产发布关闭 |
| 区域定义 | `global-v1-pending-review` 等，均带 `-pending-review` 后缀 |

| 已知阻塞项 | 每条种子以 `blockingGapIds` 列出未满足项（例：ENSO 需要独立确认来源；橡胶缺实物与日频市场；航运缺航线运价） |

## 五、如果延后

1. 聚合永远只产出 `PENDING_RESEARCH_APPROVAL`：**0 草稿、0 日报、0 公开结论**；
2. 三天 staging 演练即使资源就绪，也只能记录"延迟"，父任务 AC-05 与 AC-14 无证据；
3. 上线后公开站点仍是空状态——部署本身不会带来内容；
4. 首月人工发布缺少可发布对象，后台发布流程无法演练。
